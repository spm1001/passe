## Gotchas
- Headless Chrome with `--no-sandbox` (kube's systemd service) does NOT produce OOPiF targets — site isolation is disabled. All iframe testing needs Mac Chrome with real profile.
- `_find_root_page()` walks `/json/list` parentId chain. If Chrome omits parentId (different version, config), it falls back to `attach_to_first_page()` which may attach to the wrong tab.
- `frame` is not re-entrant (single-slot stash). `frame A; frame B` errors — must `frame top` between them.

## Risks
- Feature is completely untested against real OOPiFs. Unit tests cover the session-swapping logic, but the CDP protocol interaction with real iframe targets is unverified.
- Network capture in iframe context mixes parent and iframe traffic (documented in footgun #18, no per-session filtering).
