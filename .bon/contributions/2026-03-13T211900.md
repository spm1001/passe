Passe is becoming the single web content tool for all Claude sessions. Mise-en-space
is dropping its web fetching path entirely — it was always a weaker copy of passe's
extraction, and Claudes were confused about which tool to use.

The architecture is a four-layer escalation: content-type sniff → framework shortcuts
(Next.js __NEXT_DATA__, Apple docs JSON API) → HTTP fetch with trafilatura + quality gate
→ Chrome CDP as the last resort. The HTTP fast-path goes in cmd_fetch before the connect()
context manager — if HTTP succeeds, Chrome is never touched.

The quality gate between tiers is the novel engineering. Deep Research (March 2026) confirmed
trafilatura (F1 0.958) is still the benchmark leader. The composite scoring approach multiplies
penalty factors: word count, stop words ratio (jusText thresholds), link density (Boilerpipe's
0.33 threshold), text-to-HTML ratio, and pattern detection for paywalls/CAPTCHAs/cookie consent.

A test-first approach was chosen: build a harness against WebMainBench (7,887 pages with
markdown ground truth) before writing any extraction code, so Claudes can iterate autonomously
on extraction quality without human involvement. The harness IS the development tool.

readability-lxml + markdownify sits as a middle tier between trafilatura (fast, aggressive
boilerplate removal) and Chrome (slow, complete). It catches docs sites and complex layouts
where trafilatura strips too aggressively but the page is static HTML.

Semantic exit codes (0=good, 1=thin, 2=broken) are cheap to add and make passe fetch
composable in shell scripts — a pattern confirmed by Simon Willison's Rodney tool, which
independently arrived at the same persistent-Chrome + ephemeral-CLI architecture.
