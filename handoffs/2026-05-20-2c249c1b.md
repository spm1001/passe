## For Claudes to come

The substrate-first lesson is fractal. We already had it for two levels: (a) docs sites that fetch their own `.md` — capture network before extracting from rendered DOM (yesterday's antigravity case); (b) source code of substrates we build on — gemini-cli, Claude Code internals, framework defaults (already in self.md verification-discipline #14 and the gemini-cli `isSectionEnabled` worked example).

Today added the third level: (c) **claims about other tools' internals inside our own briefs and handoffs**. The Turndown/defuddle correction is the canonical example. Yesterday's handoff said, confidently, "Turndown (Mozilla's HTML→Markdown converter, what Obsidian Web Clipper uses)." It was wrong. OWC uses kepano's `defuddle`, not Turndown — Turndown isn't even imported. That one sentence sent the entire `passe-telari` spike investigating the wrong library; the corrective was `gh api repos/obsidianmd/obsidian-clipper/contents/src` and reading the actual `content-extractor.ts`. Verification cost: ~30 seconds. Cost of building on the wrong frame: the whole spike, recovered only by catching the substrate-first lesson recursing.

The activator: **any sentence in a bon brief or handoff that names another project's internals — "X uses Y," "X is built on Y," "X works like Y" — is inference unless someone grepped the source.** Confident phrasing doesn't change that. The cost of the 30-second `gh api`/`gh repo view`/`grep` is bounded; the cost of inheriting an inference-as-fact is structural — the next Claude reads with the same confidence the previous Claude wrote with, and the error propagates.

The fix is small and habitual: when a brief tells you "X uses Y" and the spike depends on that being true, take 30 seconds to verify before designing the experiment around Y. The substrate-first lesson isn't a one-time discovery about JS-rendered docs sites — it's a stance that applies wherever we build on someone else's work, including the work of past-Claudes who wrote our briefs.

Composes with the existing "Authoritative artefacts deserve a framing audit before being extended" entry (self.md): that's about questioning a doc's frame before extending it; this is the specific case where the frame includes claims about external tools you're about to bet a spike on. Cheap check; high leverage.
